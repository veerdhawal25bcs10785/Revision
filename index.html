About the passkey

Your passkey is set once, the first time you open Recall on a device, and stored only in this browser. There's intentionally no "forgot passkey" flow and no in-app way to erase your data — both are trade-offs for keeping this a fully static, backend-free site you can host for free on GitHub Pages.
